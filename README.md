# My EPG

Объединённая телепрограмма для IPTV-плееров.

## Ссылка на EPG

Добавьте этот адрес в качестве источника EPG в свой плейер:

**https://github.com/mireamor/my_epg/releases/download/latest/epg.xml.gz**

## Что содержит файл

- Телепрограммы из IPTVX и EPG.ONE.
- Логотипы каналов на основе проекта [Lorax121/epg_v2](https://github.com/Lorax121/epg_v2).
- Объединённый XMLTV-файл в формате GZIP.

## Обновление

Файл автоматически пересобирается ежедневно через GitHub Actions.

Адрес источника остаётся постоянным. Содержимое и контрольная сумма SHA-256 могут меняться после обновления.

## Использование в IPTV player

1. Откройте настройки EPG.
2. Добавьте новый источник EPG.
3. Вставьте ссылку выше.
4. Запустите обновление телепрограммы.

## Проект

Исходный код и автоматическая сборка доступны в этом репозитории.
